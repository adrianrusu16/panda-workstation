# Panda Theme — Design Authority and Skill Mapping

## Authority

When instructions conflict, follow:

1. Current user request.
2. Repository `AGENTS.md`.
3. Approved Panda Theme design specification.
4. Active flavor semantic manifest/tokens.
5. `panda-theme-system` skill.
6. External design skills.
7. Agent improvisation.

## Recommended external skills

### General review

Use these when installed:

- `better-colors`: semantic palettes, ramps, measured contrast.
- `better-accessibility`: focus, keyboard, contrast requirements, reduced motion.
- `better-layout`: grouping, alignment, resizing and density.
- `better-ui`: surfaces, icons, motion polish.
- `prototype`: compare distinct variants before committing to a new UI component.
- `animate`: splash and infrequent motion where motion is actually useful.
