# Panda Workstation

Reproducible CachyOS/Linux workstation configuration for Adrian.

## Goals

- Clean and fast Linux workstation
- Reproducible package installation
- Portable Fish/Git/KDE development configuration
- Android, Kotlin, C++, Rust and AOSP development
- Gaming support
- Machine-specific configuration without storing secrets

## Machines

- `panda-helios` — Acer Predator Helios 300, i7-7700HQ, GTX 1060, 32 GB RAM
- `future-amd-desktop` — planned AMD workstation
